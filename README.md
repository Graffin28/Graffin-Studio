# Graffin Studio 2.4.0

Локальный видеоредактор для вертикальных роликов: выбор исходников и речевых моментов, музыка, баннер-пауза, анимированные субтитры и экспорт MP4.

## Скачать

Готовые файлы находятся в [Releases → v2.4.0](https://github.com/Graffin28/Graffin-Studio/releases/tag/v2.4.0). Средства разработки для установки не нужны.

| Система | Файл | Установка |
| --- | --- | --- |
| macOS 13.5+, Apple Silicon | [Скачать ZIP для Mac](https://github.com/Graffin28/Graffin-Studio/releases/download/v2.4.0/Graffin_Studio_2.4.0_macOS_AppleSilicon.zip) | Распаковать и перенести `Graffin Studio.app` в «Программы». |
| Windows 10 1803+ / Windows 11, x64 | [Скачать установщик EXE](https://github.com/Graffin28/Graffin-Studio/releases/download/v2.4.0/Graffin_Studio_2.4.0_Windows_x64_setup.exe) | Запустить установщик. |

Архив для Mac содержит `.app`. Версия для Intel Mac в этот релиз не входит. Для речевых функций на Windows нужны AVX2, FMA и F16C. Windows-установщик включает медиазависимости и при необходимости устанавливает WebView2; его установка и первоначальная загрузка модели речи требуют интернета.

[Инструкция по работе](docs/usage.md). Контрольные суммы опубликованы в релизе как `SHA256SUMS.txt`.

## Статус сборок

Это сохранённые готовые сборки 2.4.0. Mac-версия ранее проверена запуском на Apple Silicon, имеет локальную ad-hoc подпись и не нотарифицирована Apple. Windows-установщик не подписан; его состав и зависимости ранее проверены, фактический запуск интерфейса и обработки видео на Windows ещё не проверен.

При переносе на GitHub новые сборки, обработка видео и полные тесты на Mac не запускались. SHA-256 готовых файлов совпадают с сохранёнными отчётами 2.4.0.

## Исходный код

Основное дерево содержит Windows-порт 2.4.0 на Tauri 2, Rust, React и TypeScript. Точные различия исходников, из которых была собрана Mac-версия 2.4.0, сохранены в [`docs/macos-2.4.0-source.patch`](docs/macos-2.4.0-source.patch). Для восстановления Mac-снимка применяйте патч в отдельной копии исходников.

- [Разработка и упаковка Windows](docs/windows-development.md).
- [Разработка и упаковка macOS](docs/macos-development.md).
- `prepare_windows_resources.py` подготавливает закреплённые Windows-зависимости.
- `prepare_media_tools.py` подготавливает речевой модуль macOS.

В Git не включены `node_modules`, результаты сборок, большие исполняемые зависимости, личные настройки, модели речи и пользовательские видео. Медиаресурсы готовых приложений входят в файлы релиза. Для повторной сборки нужны платформенные ресурсы, описанные в документации и скриптах подготовки. Лицензии сторонних компонентов сохранены в `src-tauri/resources/` и `public/fonts/`.
