# Graffin Studio 2.4

Локальная монтажная программа для вертикальных роликов на macOS Apple Silicon, macOS 13.5 и новее. Последовательность работы: исходники → выбор моментов → оформление → предпросмотр → экспорт MP4. Разделы очереди, аккаунтов и публикации удалены из интерфейса и команд приложения.

## Папки и исходники

В медиатеке можно добавлять отдельные видео или выбрать папку основных и, при необходимости, фоновых видео. Выбор папки заменяет соответствующий список исходников. Сканируются поддерживаемые видео непосредственно в папке, без вложенных каталогов; предел — 200 файлов.

Блок **«Папки»** постоянно показывает два отдельных назначения:

- **«Видео по ссылкам»** — куда загружаются исходники из URL. Путь можно изменить и открыть в Finder; тот же путь виден перед загрузкой по ссылке.
- **«Готовые ролики»** — куда сохраняются результаты монтажа. Папку также можно выбрать в верхней панели.

По умолчанию используется `Graffin Studio` в пользовательской папке загрузок, с резервным вариантом в документах. Внутри создаётся папка `Исходники по ссылкам`. Выбранные пути сохраняются в настройках. Смена папки не переносит ранее созданные файлы.

## Нарезка с проверкой моментов

В **«Нарезка» → «По смыслу»** кнопка **«Найти моменты»** запускает локальный анализ речи основных видео. Программа предлагает законченные фрагменты с текстом, временем и причинами выбора. В окне **«Выберите моменты»** можно найти фразу по слову, просмотреть исходник, снять лишние варианты и уточнить начало и конец. **«Собрать выбранные»** экспортирует только отмеченные интервалы с текущим оформлением.

Допустимая длительность выбранного момента — 5–180 секунд. Пересекающиеся интервалы одного исходника нужно развести или исключить. Анализ и сборку можно остановить; уже готовые MP4 сохраняются. Изменение исходников или параметров анализа требует обновить поиск. Для выбранных моментов субтитры берутся из проверенной расшифровки, без повторного распознавания при экспорте.

Подбор использует речевые эвристики: границы фраз, плотность речи, паузы, повторы и разнообразие. Он помогает отобрать материал, но не гарантирует интересность или просмотры. Для роликов без подходящей речи доступен режим **«По времени»**.

## Оформление

- **Кадр:** два видео или только основное. Без фона регулируется высота 50–100%; доступны заполнение, вписывание и горизонтальный фокус.
- **Текст:** по одному слову или до 2–5 слов в группе. Количество — максимум: конец фразы и длинная пауза начинают новую группу. Анимации: без анимации, плавное появление, пружина, выезд снизу. Подсветка произносимого слова включается отдельно, её цвет настраивается. Анимация запускается один раз на группу; подсветка следует времени каждого слова.
- **Шрифты:** встроенные и собственные TTF/OTF. Импортированные шрифты сохраняются в библиотеке приложения и используются при реальном экспорте.
- **Музыка:** постоянная библиотека, начало внутри трека, задержка включения в ролике, громкость, повтор выбранного участка и плавное начало/затухание. Начало можно взять из текущего положения музыкального плеера.
- **Баннер-пауза:** изображение или видео по центру. Варианты появления: середина, указанная секунда, случайная точка заданного диапазона и **«В тихом моменте»**. Последний ищет паузу в исходном звуке рядом с серединой; при отсутствии подходящей тишины использует середину. Плавное появление и исчезновение регулируется от 0 до 2 секунд на каждый край, с ограничением половиной длительности вставки.
- **Пресеты:** сохраняют оформление, включая группировку субтитров, анимацию, подсветку, музыку и баннеры. Применение пресета сохраняет текущие папки, количество, длительность, способ нарезки и порядок исходников.

Во время баннера-паузы основной кадр, субтитры и вся аудиосмесь, включая музыку, замирают, затем продолжаются с прежнего места. Баннер играет без собственного звука; короткое видео повторяется. Длительность паузы добавляется к готовому ролику. Выбранная при сборке точка вставки сохраняется для последующей правки субтитров.

Центральный монитор показывает композицию и пример текста. **«Просмотр 5 сек.»** собирает настоящий короткий MP4 с обработкой; окно найденных моментов проигрывает исходник, оформление добавляется при сборке.

## Правка готового видео и хранение данных

Редактор субтитров позволяет менять слова, время и стиль, затем пересобирает видео из исходников. Сохраняйте исходные видео, используемые материалы и скрытую папку `.graffin-edit` рядом с экспортами. Старые ролики без монтажной записи доступны для просмотра, но не для полной пересборки. Время слов в редакторе относится к исходному фрагменту; плеер учитывает баннер-паузу.

Речевой модуль подготавливается из интерфейса при первом использовании. Его модель, импортированные музыка и шрифты хранятся отдельно от установленного приложения. Для первоначальной подготовки модуля и загрузки URL нужен интернет; распознавание и монтаж выполняются локально. Качество распознавания зависит от языка, записи и фонового шума. Доступность загрузки по URL зависит от сайта и формата ссылки.

## Проверка и сборка

Для разработки нужны Node.js, совместимый с Vite 7, Rust, Xcode Command Line Tools и Python 3 для упаковки. Сохраните медиаресурсы проекта в `src-tauri/resources/`; обычному пользователю отдельная установка средств разработки не нужна.

```sh
npm ci
npm run build
cargo test --manifest-path src-tauri/Cargo.toml --lib
```

Тесты с `#[ignore]` запускаются отдельно с доступными медиаресурсами. Примеры проверок новых эффектов создают настоящие MP4:

```sh
cargo test --manifest-path src-tauri/Cargo.toml --lib ffmpeg_caption_groups_animations_and_pause_smoke -- --ignored --nocapture
cargo test --manifest-path src-tauri/Cargo.toml --lib ffmpeg_quiet_banner_fade_and_recipe_smoke -- --ignored --nocapture
```

Отчёты 2.4: `qa/graffin24-ui/results.json`, `qa/graffin24-moments/acceptance.json`, `qa/caption24-acceptance.json`, `qa/banner24-acceptance.json`. Они проверяют отдельные сценарии и не заменяют проверку собранного приложения.

Для релиза:

```sh
npm run tauri build -- --no-bundle
python3 package_macos.py --template "/путь/к/Tauri/Graffin Studio.app" --archive "/путь/к/Graffin_Studio_2.4.0_macOS_AppleSilicon.zip"
```

В качестве шаблона нужен существующий Tauri `.app`; упаковщик заменяет исполняемый файл, ресурсы и номер версии данными текущего проекта. Он проверяет локальную ad-hoc подпись и записывает метаданные в `qa/final-bundle.json`. Сборка не нотарифицирована Apple. После упаковки и установки проверяйте версию и запуск отдельно; актуальный статус релиза хранится в `state.json`.
